# P2-07 Campus Push Time Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independent reference-style P2-07 experiment for 09:00 versus 20:00 campus-community push timing.

**Architecture:** Copy only the visual shell patterns needed from P2-06 into a new directory, then use P2-07-specific pages, `p207_*` browser storage keys, a click/impression record model, and a separate Worker/D1 schema. The participant page records one exposure and an optional click; the workbench and aggregate pages calculate CTR from real records only.

**Tech Stack:** Static HTML/CSS/vanilla JavaScript, GitHub Pages, Cloudflare Worker, Cloudflare D1, Node smoke tests.

## Global Constraints

- P2-07 must not modify or read P2-06 runtime records.
- The only A/B variable is push time: A `09:00`, B `20:00`.
- Planned valid sample is 120 total, with at least 60 per group.
- Preview modes never write formal records.
- No fake sample generator, real payment, login, OAuth, or unnecessary dependencies.
- All URLs and local assets must be relative for GitHub Pages subpaths.
